
# Bài 01 - Lọc danh sách sinh viên

## 1. Nội dung thực hiện

- Sử dụng class và constructor để tạo đối tượng sinh viên.
- Khai báo danh sách gồm 5 sinh viên.
- Sử dụng arrow function kết hợp filter() để lọc sinh viên có điểm từ 5 trở lên.
- Sử dụng console.log() để hiển thị kết quả.

## 2. Các bước chạy chương trình

Bước 1: Mở thư mục Bt01 bằng Visual Studio Code.

Bước 2: Mở Terminal.

Bước 3: Kiểm tra Node.js bằng lệnh:

```bash
node -v
```

Bước 4: Chạy chương trình:

```bash
node bai01.js
```

## 3. Kết quả thực hiện

Terminal hiển thị danh sách 3 sinh viên đạt yêu cầu có điểm từ 5 trở lên.
