# Bài 6 – Xây dựng Module tính kết quả học tập

## 1. Mô tả

Xây dựng chương trình Node.js sử dụng Module để tính điểm trung bình 3 môn học và xếp loại học tập cho 3 sinh viên.

Sử dụng `module.exports` để xuất các hàm xử lý và `require()` để gọi module từ tập tin khác.

## 2. Các tập tin chương trình

 `xulyDiem.js`: Chứa hàm tính điểm trung bình và hàm xếp loại học tập.
 `bai06.js`: Gọi module, tạo dữ liệu 3 sinh viên và hiển thị kết quả.

## 3. Các bước thực hiện

1. Tạo hai tập tin `bai06.js` và `xulyDiem.js`.
2. Nhập mã nguồn và lưu tập tin.
3. Mở Terminal tại thư mục Bt06.
4. Chạy chương trình bằng lệnh:

```bash
node bai06.js
```

5. Kiểm tra kết quả hiển thị trên Terminal.

## 4. Kết quả thực hiện

Chương trình chạy thành công, tính được điểm trung bình và xếp loại học tập của 3 sinh viên:

 Nguyen Van Minh: 8.00 – Giỏi.
 Tran Thi Hoa: 7.00 – Khá.
 Pham Quoc Bao: 4.00 – Yếu.

**Kết quả chạy chương trình trên Terminal.**
