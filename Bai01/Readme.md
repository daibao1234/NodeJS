
## Bài 01: Làm quen với Node.js

### 1. Mã nguồn (`hello.js`)

```javascript
console.log("Hello World!");
console.log("Tôi đang sử dụng Node.js.");
console.log("Đây là chương trình chạy bằng Node.js.");
```

### 2. Mô tả kết quả

- Cài đặt thành công Node.js LTS.
- Kiểm tra phiên bản Node.js bằng `node -v` và npm bằng `npm -v`.
- Tạo và chạy thành công file `hello.js` bằng lệnh `node hello.js`.
- Kết quả hiển thị đúng nội dung trên Terminal, không phát sinh lỗi.
